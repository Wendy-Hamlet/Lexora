# Optional GPU runtime for OCR. Install AFTER requirements.txt:
#
#   pip install -r requirements.txt
#   pip uninstall -y onnxruntime          # the CPU wheel; see below, they cannot coexist
#   pip install -r requirements-gpu.txt
#   playwright install chromium
#
# Everything else (crawling, parsing, retrieval, the LLM client) is unchanged. This file
# only moves OCR from the CPU to an NVIDIA GPU: ~5x faster on scanned statutes, with
# identical recognised text. Skip it if you have no NVIDIA GPU -- the engine runs fine on
# the CPU wheel and says so.
#
# WHY NOT JUST INSTALL BOTH?
# onnxruntime and onnxruntime-gpu ship the SAME python module and overwrite each other's
# DLLs, so they cannot be installed side by side. They also do not need to be:
# onnxruntime-gpu already carries CPUExecutionProvider, and the engine picks the provider
# at RUN time from onnxruntime.get_available_providers(). One wheel, both paths, decided
# on the machine it actually runs on.
#
# VERSION PAIRING IS LOAD-BEARING
# onnxruntime-gpu 1.22.x links against CUDA 12, which is what the cu12 wheels below ship.
# 1.23+ links against CUDA 13: it will fail to load cublasLt64_13.dll against this set,
# then quietly fall back to the CPU. Do not bump one without the other.
#
# NO SILENT FALLBACK
# The engine reads back the providers its sessions ACTUALLY got and only names itself
# rapidocr:<ver>+cuda when all three models (det, cls, rec) are on CUDA. The name is in
# the JSON sidecar's ocr_engine field, so a CPU fallback is always visible in the output.
# LEXORA_OCR_GPU=0 forces CPU even where CUDA is available.

onnxruntime-gpu==1.22.0

# CUDA 12 runtime. Not bundled in the wheel above, hence ~2 GB of downloads -- which is
# exactly why this is a separate file and not the default.
nvidia-cudnn-cu12==9.24.0.43
nvidia-cublas-cu12==12.9.2.10
nvidia-cuda-runtime-cu12==12.9.79
nvidia-cufft-cu12==11.4.1.4
nvidia-curand-cu12==10.3.10.19
nvidia-cusparse-cu12==12.5.10.65
